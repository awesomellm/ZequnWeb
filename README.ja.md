# ZequnWeb — ウェブサイト開発と内容の資料

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [繁體中文](README.zh-HK.md)

企業サイトと実用ウェブツールを制作しています。再利用できるコード、納品用の表、ZequnWeb の実装記録を公開しています。各ガイドに英語・簡体字・日本語・繁体字の独立した版があり、本文のリンクも対応する言語へ進みます。

## プロジェクト

- [multilingual-website-starter](https://github.com/awesomellm/multilingual-website-starter/blob/main/README.ja.md)：実行できる四言語サイト：対応ページ、メタデータ、言語資料、問い合わせ下書き。
- [website-seo-checker](https://github.com/awesomellm/website-seo-checker/blob/main/README.ja.md)：静的HTMLのオフライン検査と四言語レポート。
- [website-migration-kit](https://github.com/awesomellm/website-migration-kit/blob/main/README.ja.md)：移行手順と十二種類の四言語ワークシート。
- [redirect-map-checker](https://github.com/awesomellm/redirect-map-checker/blob/main/README.ja.md)：リダイレクトの検査とCloudflare・Nginx・Apache設定。
- [practical-calculators](https://github.com/awesomellm/practical-calculators/blob/main/README.ja.md)：十二種類の計算、型宣言、例、123件の回帰テスト。
- [codex-reset-tracker](https://github.com/awesomellm/codex-reset-tracker/blob/main/README.ja.md)：公開イベントの処理、条件付き頻度、架空例、20件のテスト。
